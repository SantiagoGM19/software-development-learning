1. Definición Conceptual

¿Qué es HTML? La Analogía del Esqueleto

HTML define la estructura y el contenido de un documento web. En la arquitectura web, cada tecnología cumple una función exclusiva:

HTML (Esqueleto)
Estructura y contenido. Define los elementos (títulos, párrafos, tablas, contenedores) y su orden jerárquico. Sin HTML no existe documento ni contenido que representar.
CSS (Piel y Ropa)
Presentación visual. Controla colores, tipografías, márgenes, dimensiones y disposición espacial (layout).
JavaScript (Músculos y Nervios)
Comportamiento dinámico. Maneja eventos del usuario, manipulación del DOM, validaciones y peticiones al servidor.
Principio de separación de responsabilidades: HTML nunca debe usarse para dar estilos visuales ni lógica computacional; su única función es semántica y estructural.
1. Definición Técnica

Significado de las Siglas HTML

HyperText Markup Language (Lenguaje de Marcado de Hipertexto).

HyperText (Hipertexto)

Texto estructurado con referencias cruzadas (enlaces o hipervínculos) que permiten conectar documentos entre sí de forma no lineal a través de la web.

Markup Language (Lenguaje de Marcado)

Conjunto de etiquetas estandarizadas que delimitan y clasifican los fragmentos de un texto. No es un lenguaje de programación: no procesa algoritmos, no ejecuta bucles ni almacena variables en memoria.

Diferencia: Texto sin formato vs Texto con Marcado Semántico
<!-- Texto plano sin marcado (el navegador no conoce la función de cada línea) -->
Manual de Usuario. Descargue el archivo aqui.

<!-- Con marcado HTML (el navegador interpreta la jerarquía y el tipo de dato) -->
<h1>Manual de Usuario</h1>
<p>Descargue el archivo <a href="manual.pdf">aquí</a>.</p>
2. Sintaxis

Anatomía de una Etiqueta HTML

Un elemento HTML estándar está compuesto por tres partes formales:

<p> Texto de ejemplo </p>
1. Etiqueta de Apertura
Delimitada por < y >. Indica el inicio del elemento y su tipo semántico.
2. Contenido
Información contenida (texto, datos u otros elementos anidados).
3. Etiqueta de Cierre
Delimitada por </ y >. La barra inclinada señala el fin del elemento.
Definición técnica: El conjunto completo formado por la etiqueta de apertura, el contenido y la etiqueta de cierre se denomina formalmente Elemento HTML.
2. Sintaxis

Estructura de los Atributos

Los atributos proporcionan metadatos, parámetros de configuración o identificadores a la etiqueta. Se ubican exclusivamente en la etiqueta de apertura con la sintaxis nombre="valor".

<a href="https://w3.org" target="_blank"> W3C </a>
Nombre del Atributo
Identificador estándar que define la propiedad a configurar (href, src, class).
Valor del Atributo
Dato asignado a la propiedad. Se encierra siempre entre comillas dobles "...".
Etiqueta de Cierre
Las etiquetas de cierre nunca contienen atributos.
id="identificador"
Identificador único por documento.
class="nombre-clase"
Clasificador reutilizable para CSS y JS.
title="texto"
Información contextual (tooltip nativo).
2. Sintaxis

Elementos Vacíos (Void Elements)

Determinadas etiquetas carecen por definición de contenido textual interno y de etiqueta de cierre. Su comportamiento está regido completamente por sus atributos o por su posición.

Elementos Vacíos Frecuentes
<!-- Imagen: la fuente se define por src -->
<img src="diagrama.png" alt="Diagrama de red">

<!-- Campo de entrada de formulario -->
<input type="text" name="usuario">

<!-- Salto de línea forzado -->
<br>

<!-- Separador temático horizontal -->
<hr>

<!-- Metadato en la cabecera -->
<meta charset="UTF-8">
Comportamiento en HTML5
En HTML5, la barra de cierre final (<img />) es prescindible. Ambas formas son procesadas por el motor del navegador, pero el estándar actual recomienda la sintaxis limpia sin barra: <img>.
Diferencia con elementos normales
No admiten elementos hijos ni cadenas de texto dentro de ellos; son representados directamente por el navegador según el tipo de elemento.
3. Estructura Jerárquica

Jerarquía y Árbol DOM

Un documento HTML se organiza como una estructura de datos en árbol (DOM: Document Object Model). Las etiquetas anidadas establecen relaciones de parentesco precisas:

<section> // Padre de h2 y p <h2> // Hijo de section, hermano de p Capítulo 1 </h2> <p> // Hijo de section, hermano de h2 Texto con un enlace <a>aquí</a> </p> </section>
Nodo Padre (Parent)
Elemento que envuelve directamente a otro elemento. En el ejemplo: <section> es padre de <h2> y de <p>.
Nodo Hijo (Child)
Elemento contenido dentro de otro. <a> es hijo de <p> y descendiente de <section>.
Nodos Hermanos (Siblings)
Elementos que comparten el mismo padre directo en el mismo nivel: <h2> y <p>.
3. Sintaxis y Errores

Regla de Anidamiento: Cierre LIFO

Last In, First Out (Último en entrar, primero en salir): La última etiqueta en abrirse debe ser obligatoriamente la primera en cerrarse. Las etiquetas nunca deben cruzarse.

Sintaxis Correcta 
<p>
  Texto con formato <strong>destacado</strong>.
</p>
<strong> está completamente contenido dentro de <p> y se cierra antes que este.
Sintaxis Incorrecta (Etiquetas solapadas) 
<p>
  Texto con formato <strong>destacado</p>
</strong>  <!-- Error de jerarquía -->
Rompe el árbol del DOM. Aunque el navegador intenta corregirlo automáticamente, provoca inconsistencias en estilos CSS y manipulación con JavaScript.
Indentación: El uso sistemático de sangría (2 espacios por nivel de profundidad) refleja visualmente la jerarquía del DOM y previene errores de anidamiento.
4. Estructura de Archivo

Estructura Global del Documento HTML

Todo archivo HTML5 válido requiere cuatro bloques estructurales mínimos:

index.html (Estructura Estándar)
<!DOCTYPE html>
<html lang="es">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Título de la Página</title>
  </head>
  <body>
    <h1>Encabezado visible</h1>
    <p>Contenido renderizado en pantalla.</p>
  </body>
</html>
<!DOCTYPE html>
Indica al motor del navegador que el documento sigue la especificación HTML5 (evita el modo quirks).
<html lang="es">
Elemento raíz que envuelve la totalidad del documento. Define el idioma para motores de búsqueda y lectores de pantalla.
<head>
Cabecera de metadatos (codificación UTF-8, viewport para dispositivos móviles, enlaces a hojas de estilo, título de pestaña). No es visible directamente en el viewport.
<body>
Cuerpo del documento. Contiene todos los elementos visuales y de interacción que el navegador renderiza al usuario.
4. Elementos de Texto

Etiquetas de Texto y Encabezados

Elementos destinados al marcado de información textual y estructuración de contenidos:

Encabezados Jerárquicos (<h1> a <h6>)
Establecen niveles de importancia estructural, no meramente tamaños de fuente: 
<h1>Título principal (uno por documento)</h1>
<h2>Sección principal</h2>
<h3>Subsección temática</h3>
<!-- <h4>, <h5>, <h6> según profundidad -->
Párrafos y Marcado en Línea
Diferencian bloques de lectura y fragmentos con significado específico: 
<p>Bloque de párrafo estándar.</p>
<strong>Importancia grave o alerta (negrita semántica)</strong>
<em>Énfasis tonal (cursiva semántica)</em>
<span>Contenedor en línea genérico sin valor semántico</span>
Criterio técnico: Nunca use <h1> para agrandar texto o <strong> solo por estética visual; para fines visuales debe usarse CSS (font-size, font-weight).
4. Organización y Conexión

Listas y Enlaces

Mecanismos para agrupar elementos ordenados o no ordenados y para conectar recursos web.

Listas (<ul>, <ol>, <li>)
El elemento <li> (list item) solo es válido como hijo directo de <ul> u <ol>: 
<!-- Lista no ordenada (viñetas) -->
<ul>
  <li>Elemento A</li>
  <li>Elemento B</li>
</ul>

<!-- Lista ordenada (secuencial numerada) -->
<ol>
  <li>Primer paso</li>
  <li>Segundo paso</li>
</ol>
Enlaces Hipertexto (<a>)
Permite la navegación interna, externa o mediante protocolos de red: 
<!-- Enlace externo en pestaña nueva con seguridad rel -->
<a href="https://developer.mozilla.org" 
   target="_blank" 
   rel="noopener noreferrer">MDN Docs</a>

<!-- Enlace relativo interno -->
<a href="/perfil/configuracion.html">Ajustes</a>

<!-- Enlace a sección por ID interno (ancla) -->
<a href="#seccion-2">Ir a Sección 2</a>
4. Interacción y Recursos Externos

Multimedia y Formularios

Incrustación de recursos externos y captura de datos del usuario:

Recursos Multimedia (<img>, <video>)
<!-- Imagen con atributo alt obligatorio para accesibilidad y SEO -->
<img src="servidor.jpg" alt="Servidor rack en centro de datos">

<!-- Reproductor de video nativo -->
<video controls width="640">
  <source src="clase.mp4" type="video/mp4">
</video>
Entrada de Datos (<form>, <input>, <button>)
<form action="/api/registro" method="POST">
  <label for="email">Correo electrónico:</label>
  <input type="email" id="email" name="email" required>

  <button type="submit">Enviar</button>
</form>
Asociación semántica: El atributo for de <label> debe coincidir exactamente con el id del <input> para permitir enfoque al hacer clic y compatibilidad con tecnologías de asistencia.
4. Estructuración Semántica

HTML Semántico: Contenedores Estructurales

Sustitución de contenedores genéricos (<div>) por etiquetas descriptivas que expresan el rol arquitectónico de cada bloque:

<header> & <nav>
<header>: Bloque introductorio o cabecera de la página o de una sección.

<nav>: Contenedor reservado exclusivamente para bloques de enlaces de navegación principal.
<main>, <section>, <article>
<main>: Contenido central y exclusivo del documento (único por página).

<section>: Sección temática genérica con encabezado propio.

<article>: Contenido autónomo y redistribuible por sí mismo.
<aside> & <footer>
<aside>: Contenido tangencial o complementario (barras laterales, glosarios).

<footer>: Pie de página o de sección (información de autoría, derechos, enlaces legales).
Comparación: Maquetación no semántica vs Maquetación semántica
<!-- No semántico (todo es un contenedor genérico div) -->
<div id="cabecera">...</div>  <div id="cuerpo">...</div>  <div id="pie">...</div>

<!-- Semántico estándar HTML5 -->
<header>...</header>       <main>...</main>         <footer>...</footer>
